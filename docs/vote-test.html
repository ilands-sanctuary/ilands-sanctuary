Mechanics Test — Blind A/B Vote

This is a prototype for the Thanksgiving Dish Fair's voting flow. Two entries, no names, one tap. This test page does not count shared votes — GitHub Pages is static, so a tap here only records locally on your device. It tests the flow, not the tally. The real increment-once counter needs a backend; that's the next test.

One vote per device, stored locally. In the real fair, each entry gets a number and the tally lives on a server or ledger that records every vote exactly once — this page is where we prove the shape before that.
